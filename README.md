# DonutDB 🍩

DonutDB is a lightweight, embedded SQL database engine written in C++. It aims
to provide a compact, self-contained storage engine, prioritizing simplicity and
portability.

The project covers the core components of a relational database system,
including storage, indexing, SQL parsing, and query execution.

## Status

Early development. Not suitable for production use.

## Planned features

- Single-file database storage
- B-tree based tables and indexes
- Basic SQL support (CREATE, INSERT, SELECT, UPDATE, DELETE)
- Simple command-line shell
